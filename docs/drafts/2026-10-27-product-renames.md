# Product renames — draft for owner review (2026-10-27)

Spec 042 Phase B, part B2. The product name is the start of every product page title, and most searches that reach
pw2d product pages are a bare model name ("aoc gk330", "aula f106 pro"). These names start with a description
instead of the brand and model, or end in a stray `-` / `|`.

**What a rename changes:** the name on the page, in the title, on guide cards and in comparisons. **What it does not
change:** the URL (slugs stay), scores, prices, guides' written text. No rescan, no AI call
(`ProductObserver` reacts only to hidden / category changes).

**Rule used:** brand + model + only what tells two listings apart (Wired vs Wireless, Single Kit, frequency band).
The page title adds the category, so "Mechanical Gaming Keyboard" is not repeated in the name.

**How to review:** strike or edit any line below. Anything you don't touch is applied as written.
